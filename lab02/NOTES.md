Привет

Различие между Git и GitHub: Git — это локальная программа для контроля версий на компьютере. GitHub — это облачный сервис в интернете для хранения репозиториев и совместной работы.

Использованные команды:

\- git status: показывает состояние файлов в рабочей директории и индексе.

\- git diff: показывает изменения в файлах, которые еще не добавлены в индекс.

\- git diff --staged: показывает изменения, которые уже добавлены в индекс.

Ветки: Ветка — это независимая линия разработки. Новый коммит сдвигает её вперед. Слияние (merge) объединяет изменения из разных веток.
